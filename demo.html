Screenshot UI grounding demo

UI grounding as a prerequisite for computer-use agents

This tab targets the Screenspot-Pro benchmark setting: given a UI screenshot and a natural-language instruction, the agent must understand the interface, identify the requested UI element, and ground the answer as normalized coordinates. The task focuses on multimodal UI understanding and precise visual grounding, which are core preconditions before a CUA agent can reliably click, type, or operate software. Each task also comes with lightweight inspection tools, so the agent can crop, zoom, annotate, and verify small interface targets before writing the final JSON answer.

Multimodal UI understandingRead visual layout, text labels, icons, and interaction affordances from screenshots.
Grounding before actionReturn precise bbox or point coordinates before attempting downstream UI control.
Tool-assisted solvingUse bundled crop, zoom, and grid annotation scripts to inspect difficult targets.
Locate the requested target in the screenshot and write strict JSON to `./answer.json`.
Use normalized coordinates 0-100 (top-left = 0,0). Return a bounding box `{"bbox": [x1, y1, x2, y2]}` or a point `{"point": [x, y]}` as required.
Read image files directly with your native image reader (do not use `cat`). You may crop, zoom, or annotate using `./skills/screen-tools` to inspect small UI elements. Always verify the output file contains valid JSON and all coordinates are between 0 and 100.

Workdocs finance reasoning demo

Expert-level multi-document reasoning over financial PDFs and spreadsheets

This tab is separate from Screenspot-Pro. It displays workdocs tasks: expert-level multi-document reasoning problems over financial reports, PDFs, tables, and spreadsheets. These examples emphasize evidence extraction, cross-file reconciliation, quantitative reasoning, and rubric-driven grading. Each task folder contains a Prompt.txt with the questions, a Rubrics.txt with grading criteria, and a parallel Files/ bundle with the source materials.

Multi-document evidenceReason across several files instead of one screenshot.
Finance-domain calculationsCompute movements, shares, percentage changes, and comparisons.
Programmatic rubric viewParse rubric text into criteria, weights, and pass/fail status.
